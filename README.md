# Post Apocalyptic Space Cruise 🚀

A tiny procedurally generated 3D space exploration demo built with Claude Code.

Explore 700 star systems, discover planets and moons, and cruise through a galaxy generated directly in your browser.

**[Play the demo](https://wherearethey.dev/cruise/)**

## Features

- 700 procedurally generated star systems
- Different star types, including black holes and neutron stars
- Rocky planets, gas giants, and moons
- Proximity-based ship speed adjustments
- Procedural textures and synthesized audio
- WebGL2, without a 3D engine
- All JavaScript and shaders in a single ~28 KB HTML file

## Background

Inspired by [Abyssal Garden](https://github.com/Noniv/abyssal-garden).

Star and planet distributions are based on [WHERE ARE THEY?](https://wherearethey.dev/), a 2D space exploration roguelike.

The demo was created with Claude Code through an initial prompt and subsequent iterations.

**Note:** The start screen uses an externally loaded font and GIF.
